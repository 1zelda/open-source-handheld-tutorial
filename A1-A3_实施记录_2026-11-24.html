三、A2：NLI 影子语义层

生产契约

  • 模型：MoritzLaurer/mDeBERTa-v3-base-mnli-xnli；固定 revision：8adb042d524ecd5c26d3e3ba0e3fbcf7e2d0864c。
  • 设备与精度：CUDA FP32；不静默回退 CPU。
  • 输入：候选证据作为 premise，完整原子主张作为 hypothesis；禁止拿问题冒充主张。
  • 位置：身份、版本、权限等硬闸门之后；结构化事实不交给 NLI 替代硬判据。
  • 权限：只能产生 supports_shadow、veto_candidate、uncertain、not_applicable、not_run；不能创建或撤销生产 pass。
  • 多域：kb.query_auto() 把参数透传每个命中域，不合并成一个总 pass。
  • 日志：只存标签、概率、margin、阈值、设备、revision 和字符数，不存 claim/premise 正文。

四、A3：付费 API 与凭据安全

付费执行闸门

闸门当前行为
未知价格按收费处理；即使 --allow-paid 且预算完整，也因未知价格拒绝请求。
点名型号只限制型号，不绕过 --allow-paid 和预算。
六项预算/额度每轮/每日金额、token、请求上限必须全部 > 0；token/请求须为整数。当前全部为 0，付费执行直接拒绝。
输入估算未接 tokenizer，按 UTF-8 字节数取保守上界；默认输出上限 2048，显式 --max-tokens 原样保留。
真实用量成功后回填 attempts、req、输入/输出/思考 token 与人民币成本；Gemini 思考 token 计费。
中断/超时请求发出后若进程中断或传输层结果未知，台账保留 pending；后续付费调用按未知成本拒绝。
并发生产 --ask/--init 使用 Windows 文件锁，锁内重读配置与台账；第二进程直接拒绝。

凭据安全

  • 密钥值只存 Windows Credential Manager；JSON 只存凭据引用。
  • 本轮扫描：配置与台账的敏感字段命中均为 0，疑似密钥值命中均为 0；1 个凭据引用存在且可读。
  • 掩码只显示“已配置（N 字符）”，不输出首尾片段。
  • save() 在打开临时文件前递归拒绝敏感字段和常见密钥值；被拒绝时目标文件与 .tmp 都不生成。
  • .gitignore 已验证覆盖配置、台账、对应 .tmp 与脚本备份。
