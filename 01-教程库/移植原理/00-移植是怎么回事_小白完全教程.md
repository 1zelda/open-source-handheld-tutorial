## 二、先把"移植"这个词讲清楚：六条完全不同的路线

新手最大的坑是把下面六件事统称为"移植"。它们的**工作量、法律处境、成品长相**完全不同。

| 路线 | 谁写的代码 | 游戏素材从哪来 | 有没有"解压即玩"的成品 | 典型例子 |
|---|---|---|---|---|
| **A 官方移植** | 原厂商自己 | 厂商自己的 | 有（商业产品） | GTA 三部曲的重制/移动版、任天堂 Switch VC |
| **B 模拟器** | 模拟硬件的人 | **你自己的原版** | 有核心 + 你自己 dump 的 ROM | RetroArch 的 PCSX ReARMed / DuckStation / mgba |
| **C 引擎重实现**（reimplementation） | 社区**从零重写**引擎，一行原版代码都不用 | 只用原版的**数据文件** | 通常只发源码或引擎，不发游戏 | `rwengine/openrw`(GTA III)、ScummVM、ioquake3、dxx-rebirth、OpenRA |
| **D 反编译 / 重编译**（decomp / recomp） | 把**原版二进制**逐函数还原成 C 源码再重编 | 素材仍在原版里 | 成品里通常**就是原厂程序码翻译出来的二进制**，所以本库对这一类**只收源码** | `FoxdieTeam/mgs_reversing`、`ChanseyIsTheBest/sa2-nx`、`centollOS/SwitchWaker`(风之杖)、`sonicretail/su-recomp`、`ChanseyIsTheBest/MarathonRecomp-NX`(索尼克 2006 X360 版 → Switch，**本库只收源码快照 4,115,248 B**) |
| **E 原版可执行文件的包装 / 劫持**（wrapper / loader） | 社区写"环境"，**代码本体还是官方的** | 官方那份 ARM 可执行 + 数据，都要你自备 | 一般发一个 `.nro` / 启动器 | `TheOfficialFloW/gtasa_vita`、`NaGaa95/gtasa_nx`、`mariob0y/gta3-nx` |
| **F 只是补丁 / mod** | 不改平台，只修原版 PC/主机版 | 你已装的正版游戏 | 是 mod，**不是移植** | `ThirteenAG/MGSHDFix`、`MaxPayne3.FusionFix`、各种 60FPS patch |

看懂这六条线之后，"你帮我找个 GTA5 移植"这个问题就自动变成三个可查的问题：

1. 它是 **C/D** 还是 **E**？（C/D 意味着作者自己写或还原了代码；E 意味着你其实是在跑官方那个二进制）
2. 它要我**自备什么**？（数据、可执行文件、还是整个游戏）
3. 它有没有**成品**、成品里有没有**原厂素材**？

**⚠️ 关键区别**：E 类（wrapper）法律上最微妙 —— 它分发的是"跑官方二进制的能力"，官方二进制本身要你自己买。
`mariob0y/gta3-nx` 的 Legal 小节把这件事写得非常干净，值得照抄成判断标准：

> *"This repository contains **no game code and no game assets**. `libGame.so`, `libc++_shared.so` and everything under `assets/` are Rockstar Games' copyrighted property and must come from your own legally purchased copy of the Android release."*
> *"The port code is MIT licensed."* —— `mariob0y/gta3-nx` README:200-207

## 三、为什么凡是合法移植都写着"请自备正版"

**代码和素材是两套版权，而且只有前者可以开源。**

- 引擎代码：作者自己写的 → 想给什么许可都行（MIT / GPL / Apache）。
- 游戏素材：模型、贴图、动画、关卡数据、音乐、配音、剧本 → **永远是 Rockstar / Konami / Remedy / Take-Two 的财产**。
  哪怕作者把引擎 100% 重写，把素材一起打包分发仍然是复制发行他人作品。

所以你会看到所有正经项目都留一句几乎一样的话，这不是客气，是**法律边界**：

| 项目 | 原话（我本轮亲自抓的） |
|---|---|
| `orktes/max_arm64`（Max Payne 移植） | *"No assets or program code from the original game or its Android port are included in this project. We do not condone piracy in any way, shape or form and encourage users to legally own the original game."* —— README:100 |
| `rwengine/openrw`（GTA III 引擎重实现） | *"A legitimate copy of the original PC game is required to run OpenRW. Without this it will not be possible to play."* —— README:10 |
| `FoxdieTeam/mgs_reversing`（MGS PSX 反编译） | *"`ISO` is a path to ISO/ECM/BIN file with the original game (SLPM-86247)."* —— README:2049；`:2084` 进一步要求 *the original files of Metal Gear Solid: Integral from the CD-ROMs* |
| `c22dev/muguet`（所谓 GTA V 移植） | *"Because I care about me not getting sued, you will need your own copy as a `.zip`"* —— README:13 |

**⚠️ 而且"开源"不等于"安全"。** 反例是硬的：GTA III 最有名的引擎重实现 `GTAmodding/re3` 现在已经被 GitHub 按 DMCA 封锁，
本轮直接打 API 拿到的响应是：

```
HTTP 451
{"message":"Repository access blocked",
 "block":{"reason":"dmca","created_at":"2021-09-30T17:33:39Z",
 "html_url":"https://github.com/github/dmca/blob/master/2021-09-2021-09-29-take-two-legal-action/2021-09-29-take-two-legal-action.md"}}
```

`mariob0y/gta3-nx` README:23-26 就是因此改走安卓路线的：*"**The Switch port repo was DMCA'd.** The upstream is gone."*
含义有三层，请一定记住：
1. **被下架 ≠ 作者是小偷** —— re3 是自写引擎，仍然被下架；
2. 所以本库宁可对"看起来没问题"的包也保持严格判据，不追一个随时消失的链接；
3. **一个仓库今天能 clone，不代表明天还在**，这就是我们把每个产物都算哈希、并把判定写进台账的原因。

`gtasa_vita` 的做法是 E 类的教科书样本，README 原话：

> *"The port works by loading the official Android ARMv7 executable in memory, resolving its imports with native functions and patching it in order to properly run. By doing so, it's basically as if we emulate a minimalist Android environment in which we run natively the executable as is."*

—— 它不重写 GTA，它**造一个小安卓环境把官方的 `libGTAMobile.so` 直接跑起来**。所以没有官方二进制就没有游戏。

#### 🚫 GTA V：为什么我明确不做，以及为什么"自用不商用"救不了

事实核过：GTA V 源码在 2023-12-24 被 Telegram 用户放出约 4 GB（BleepingComputer 首发报道），2026-09-18 GameSpot 报第二轮约 **192 GB**，
2026-10 那些"浏览器玩 GTA5"的站点用的就是泄露代码编译出来的 build。`muguet` README:5-6 直说它跑的是 `game.wasm`，
并且 *"It's basically the same source as the web port."* Rockstar 从未发布过 GTA V 的网页版 —— 那条链的起点就是泄露物。

我拒绝的理由，三条，都不打折：

1. **"自用""不商用"在著作权和商业秘密上都不是抗辩。** 它改变的是被发现的概率，不是行为的性质。
2. **碰过泄露代码会污染你自己以后的作品。** 你要的终局是做出一款游戏；一旦你的代码路径里混进过他人专有源码，
   将来别人只要指出"你读过那份东西"，你的作品就得自证干净 —— 这是最贵的一种坑，比省下的几小时贵一万倍。
3. **这类 dump 是本圈最主要的恶意载荷渠道。** 192 GB 的"源码包""整合包"里塞后门是常规操作，而不是意外。

**能给的**：GTA 家族的合法移植全表、`mgshdfix` 之类补丁的性质说明、以及 §六 那条真能在这台 XF45V 上跑出画面的自备数据路线。
**不给的**：泄露源码、被 DMCA 的仓库镜像、GTA V 的任何 build、以及任何"帮你找网盘"的服务。

|---|---|
| **端口包 / port** | PortMaster 里那 2~20 MB 的 zip：**只有引擎 + 启动脚本**，不含游戏 |
| **自备数据 / needs_data** | 清单里的字段：作者不提供游戏内容，你得自己有 |
| **availability** | 上游字段。`full`=文件全包含；`demo`=自带试玩；**`free`=素材免费但要你自备**；`paid`=要你买过原版。把 `free` 读成"免费自带"是经典错误 |
| **arch** | 指令集。`aarch64`=64 位，`armhf`=32 位。你机器报 `aarch64` |
| **`attr.reqs`** | 设备能力要求（`!lowres` / `opengl` / `analog_2`），**跟要不要自备数据无关** |
| **`.nro`** | Switch homebrew 的单文件可执行程序 |
| **ELF / Mach-O** | Linux / Apple 的可执行文件格式（`muguet` 就是把 wasm 换成 Mach-O 跑） |
| **OBB** | 安卓游戏的"扩展数据包"，APK 只是程序本体 |
| **`.pk3` / `.hog`+`.pig`** | Quake III / Descent 的游戏数据容器 —— 这类引擎成品要求你把这些拷进目录 |
| **decomp / recomp** | 反编译 / 重编译：把原版机器码还原成 C 再重编，产物里通常不含素材 |
| **clean-room** | 只看行为描述、不看源码地重写 —— 唯一能站住的"重写"，代价是工作量极大 |
| **shareware / rtr** | 试玩版数据；`rtr: true` = Ready To Run，下完就能玩 |
| **DMCA / 451** | 版权下架；GitHub 返回状态码 451 = 仓库被法律原因封锁 |
| **digest / sha256 / MD5** | 文件指纹。上游发布指纹，我逐字节重算比对 —— 这就是"能不能对上账" |

## 六、动手：在 XF45V 上把一个"要自备数据"的移植跑起来（通用六步）

下面用 `gta3` 举全流程，`maxpayne` 只在需要换文件处标注。**每一步都对应一条真实命令。**

### 步骤 0 —— 先确认机器和固件

- 你的机器是 **XiFan XF45V**（RK3326，4×Cortex-A35，1 GB DDR3L，**1024×768**），**不是 R36S**；按 640×480 写的教程/主题套上来会错。
- 主固件 **ArkOS4Clone**：上游 `lcdyk0517/arkos4clone` 的设备清单里就有你 —— `02-模拟器库/已clone仓库/R36S专用/arkos4clone/Changelog.md:218`
  列了 `XiFan[Mymini,...,XF40V,DC40V,XF28,R36MAX2,XF45V,DC45V,RF45V]`。
- 它是 **64 位** 的：`Changelog.md:10` *"arkos4clone can directly open 64-bit RetroArch cores with glibc greater than 2.30"*，
  rootfs 里是 `/usr/lib/aarch64-linux-gnu/`，构建时拉的是 `runtimes.all.aarch64.zip`。
  **这就是为什么 `gta3` / `maxpayne` 这类 `arch:["aarch64"]` 的端口对你不是死路。**
- 本地镜像 `02-模拟器库/已clone仓库/系统镜像/ArkOS4Clone-20260930.img.xz` 已过 `xz -t` 整流 CRC64，SHA256 在台账里。重下：`bash _工具脚本/dl_akos4clone.sh`。

### 步骤 1 —— 确认设备上报的能力（这一步决定可装列表）

设备上：

```bash
sudo console_detect --json          # 看它眼里你的机器是什么
cat /proc/device-tree/model         # 你的 dtb 里是 "XiFan XF45V"
```

**⚠️ 一个我先前写反过、现已用代码更正的点**：PortMaster 的权威设备表 `devices.json` 有 40 个设备，**含 `r36s` 不含 `xf45v`**，
看起来像"你的机器一个端口都装不了"。实际上装机过滤走的是**能力标签**：
`harbourmaster/harbour.py:1154` 取 `device['capabilities']` → `util.py:700 match_requirements()` 判定；
`ports.json` 里那份 `attr.avail` 设备白名单**只被网站读**（`PortMaster-Website/docs/js/games_fuse.js`），设备上没有任何脚本读它。
你上报的是 `aarch64 + 1024x768 + hires + analog_0/1/2 + 1gb`，反查 1393 个 r36s 条目：要求 `!lowres` 的 49 个、要求双摇杆的 37 个**你都满足**。
（详见 `00-XF45V完全指南.md:203-212`）

可选：`echo r36s > /home/ark/.config/.CUSTOM_DEVICE` 只统一界面机型名和按键预设索引，**不会**把系统骗成 640×480。

### 步骤 2 —— 找到条目，看清它到底要什么（别猜，读字段）

电脑上（在 `F:\开源掌机教程` 下）：

```bash
grep -i "^gta3\|^gtavc\|^maxpayne\|^quake3\|^descent" \
  "04-游戏资源库/公版与开源游戏/portmaster_r36s_全清单.tsv" | cut -f1-7
```

本轮实测这几行的关键字段（第 5 列 `game_data` 就是"要不要自备"）：

```
maxpayne   Max Payne        2.9  aarch64  paid        needs_data  fps
gta3       Grand Theft Auto 3   6.8  aarch64  ?         needs_data  action
gtavc      GTA Vice City    6.2  aarch64  ?         needs_data  action
```

**⚠️ 这张清单有一列会骗你**：`game_data` 对 `descent` 也写 `needs_data`，可上游 `attr` 里 `descent` 是 `rtr: true` 且装机说明写 *"Ready to play with shareware and demo files"* —— 试玩版数据就能直接玩，不用买。
**判"到底要不要掏钱"要回读 `ports.json` 的 `attr.availability` + `attr.rtr` + `attr.inst` 三处交叉看，别只认派生清单里的那一列。**

GTA III 的装机说明原话（`ports.json` 的 `attr.inst`）：

> *"Copy all files from the original game to roms/ports/gta3. The game requires assets from the classic version released in 2001 (**not** the Definitive Edition, 2021). Versions from Steam and Rockstar Store are confirmed to work fine."*

**⚠️ 这句里的坑**：GTA III/VC 的"经典版"在 2021 年 Definitive 版上架时**从各商店下架**（`mariob0y/gta3-nx` README:29-30 也写了 *"was delisted from every storefront"*），
所以"我买了 Definitive 版"不能当素材源用。买之前先在商店里确认你拿到的是经典版文件结构。

### 步骤 3 —— 弄到"你自己的那份数据"

合法来源只有三种，本库只支持这三种：

| 情况 | 怎么办 |
|---|---|
| 已在 Steam / GOG / Rockstar Store / Google Play 买过 | 从**你自己的**安装目录或已购列表里取文件（Max Payne 走 APK+OBB：手机上装 1.7 版，用 APK 提取工具或连电脑拷） |
| 有实体盘/卡带 | 自己 dump：流程见 `03-BIOS库/自制提取路径.md`，归位与去重用 `_工具脚本/rom_sort.py` |
| 什么都没买过 | **先买。**这是这条路唯一真正的门槛，没有绕过它又不脏的办法 |

### 步骤 4 —— 摆文件、装端口

```bash
# 卡 1（不要把 ports 相关目录挪到第二张卡，见 §八 坑 3）
/roms/ports/gta3/       <- 原版游戏的全部文件（游戏自己会读）
/roms/ports/maxpayne/   <- Max Payne Mobile 的 APK(1.7) + OBB
```

然后在设备上 **ES → Ports → PortMaster（或 harbourmaster）** 里选对应条目安装；端口包只 2~7 MB。
如果你想在电脑上先校验上游包对不对，MD5 已在清单第 11 列，例如：

```bash
md5sum maxpayne.zip   # 期望 5d853718d059087c3bbd4990570d9c0e
```

### 步骤 5 —— 首启动与配置

- Max Payne 首次启动会**解包 APK/OBB，要等几分钟**（上游 README 明写），别以为死机就拔卡。
- 生成配置后再改：`/roms/ports/maxpayne/conf/config.txt`（`use_bloom`、`trilinear_filter`、`disable_mipmaps` 等）。
- GTA III/VC 的摇杆手感靠 `LeftStickSens` 之类参数调（装机说明第二段就是讲这个）。

### 步骤 6 —— 1024×768 的专属调整

| 症状 | 原因 | 处理 |
|---|---|---|
| 画面四周黑边 | 端口按 640×480 硬编码 | 正常，不会错位；别去找"全屏补丁" |
| UI 素材糊 | 用了 R36S 的 640×480 主题 | 只挑上游标 `768P` 的主题/logo（`00-XF45V完全指南.md:65`） |
| 3D 端口掉帧 | 像素是 R36S 的 **2.56 倍**、1 GB RAM | 内部分辨率别拉高；先按 1×/2× 试 |
| 按键不对 | 机型名索引的预设不同 | 删 `/boot/.console` 强制重新检测（`00-XF45V完全指南.md:190`） |

## 八、这一路上的六个坑（都是我踩过的）

1. **⚠️ "能装" ≠ "能玩"。** 本文凡是上游代码/镜像字节支持的是硬事实；凡是性能判断（Max Payne 在 XF45V 上顺不顺、MGS 掉不掉帧）**都是推算**，请以实机为准。
2. **⚠️ `free` 不是"免费自带"。** 上游 `attr.availability` 的 `free` 原义是 *Free external assets needed*（要你自备，只是素材免费）。读错会让 77 个包被误标成"解压即玩"。
3. **⚠️ 双卡用户：ports 的依赖只装在卡 1。** `arkos4clone/Changelog.md:33` 修了"ES 切到卡 2 时 ports 崩溃"，但明确注明依赖仍在卡 1。别把 ports 目录挪走。
4. **🚫 上游"修闪退"的包里可能混着商业游戏本体。** 我拆过 `ArkOS4Clone_Ports_Fixed` 里的 `死亡细胞GOG版.7z`：除启动脚本外还有一个 47,967,072 字节的 aarch64 专有 ELF。
   按本库原则我只保留了那份 5,806 字节的 `.sh`，7z 删了。`怒之铁拳4.7z` 里只有一个 `libharfbuzz.so`（纯库修复），所以整包留下。**逐包 `zipfile.namelist()` 实测，别信包名。**
5. **⚠️ 同一 URL 会瞬态 404 / 429。** 判断一个源可达不可达，必须重试两三次；单次失败什么都证明不了（索尼官方页实测过这个现象）。
6. **⚠️ 整合包到不了几百 G 的合法部分。** jam/自制/端口单个几十 KB~几 MB；"几百 G"只可能是商业 ROM 全集 —— 那要走"自己 dump + `rom_sort.py` 归位/去重"，不是让我批量抓。

## 九、没有移植的时候，还有什么路（按可行性排序）

1. **模拟器**：你这台机器的舒适区是 GB/GBC/MD/SFC/FC/PCE/GBA/PCE 满速，PS1/N64 挑游戏，PSP/DC 勉强，**PS2/GC/Wii/3DS/Switch 不要期待**（`00-XF45V完全指南.md:247-255`）。
2. **等 / 催**：移植是个人作者用业余时间做的。想推动，就去仓库提 issue、给 star、按作者的 donation 通道支持；**不要**去问"能给个带游戏的包吗"——那是把作者推向 DMCA。
3. **换平台**：MGS 想爽玩就回 PS1 原版/MASTER COLLECTION；GTA V 想玩就在 PC/主机买正版 —— 移植圈不会替你重写一个 100 美元 3A 的引擎。
4. **自己写**：真想搞明白引擎重实现怎么做，走 `01-教程库/00-C++学习路线.md`，从 RetroArch/gambatte 源码读到自写 GB/GBA 游戏；
   反编译方向可以读 `mgs_reversing` 的 `asm/`（**读注释、不搬素材**）和 `psy-q-decomp`。

## 十一、硬边界（写在教程里，是因为小白一定会被这些地方骗）

本库（以及我给你做的任何事）**永不做**以下六条，这条闸门在代码里是硬的，不是口头承诺：

```python
BAN = re.compile(r"\.nsp$|\.xci$|\.iso$|keys.?dump|merged_keys|prod.keys|romset|warez|dump pack", re.I)
```

1. 🚫 **不批量抓取商业 ROM / 主机 BIOS。** 要就走"自己 dump + 校验"。
2. 🚫 **不下载、不镜像、不分析泄露/被盗源码与 build**（GTA V 2023-12 与 2026-09 两轮 dump、playgta5 式网页版都属于这类）。
3. 🚫 **不碰改存档 / 联机作弊工具**（`YimMenu`、`Menyoo`、PKHeX 类、`niceboat0/GTA5-Switch-Toolbox` —— 后者已在登记表里点名 `enabled=0`，理由是仓库 `license=none` 且内含 GTA5 预设存档）。
4. 🚫 **不碰烧录芯片固件（Picofly 一类）、降级工具。**
5. 🚫 **无上游哈希的网盘包 / QQ 群整合包不进池。** 校验不过的字节等于没有。
6. 🚫 **不收把原厂素材 commit 进仓库的"移植"。** 判据来自读文件正文，不看仓库自述的 `spdx_id`。

**为什么"自用/不商用"不能作为放行理由**：它不改变行为性质，只改变被发现概率；
它会污染你未来自己的作品（你要做游戏，这是最贵的一种坑）；
而且这类请求的供给端（泄露 dump、整合包）正是本圈最主要的恶意载荷渠道。
