# 踩坑排查速查(症状 → 原因 → 处理)

按症状查,这是掌机折腾 90% 的问题来源。

## 刷完机开不了机 / 黑屏
- **卡没格式化对**:多数 CFW 要求 microSD **FAT32、64KB 簇(cluster size)**。Windows 自带的格式化对大容量卡默认给 exFAT,直接刷进去就是黑屏。用 SD Card Association 的 `SD Memory Card Formatter`,或 `Rufus` 只作格式化用。
- **TF1/TF2 搞反**:RG35XX 系列、Miyoo 的刷机一般要求镜像写 **TF1**(有些机型只有 TF1 有效)。插错卡槽表现就是"完全没反应"。
- **卡本身不行**:杂牌卡/扩容卡是黑屏的头号硬件原因。买三星/闪迪/金士顿正品,容量 ≤128GB 兼容性最稳(部分老固件读不了 256GB+)。
- **OTA/更新中断**:刷完第一次启动别急着关机,OnionOS/GarlicOS 首次开机会展开文件,断电就废。

## 游戏列表里没有游戏
- 目录名和大小写完全要对固件规定(`ROMS/GB`、`ROMS/GBC`,不是 `roms/gb` 看固件而定)。
- 扩展名不在扫描白名单:`.gb .gbc .gba .nes .sfc .smc .md .gen .bin .n64 .z64 .v64 .cue .chd .pbp .nds .iso .7z .zip`。有的固件默认不扫压缩包,先解压试试。
- **文件是垃圾**:下载站常给 `.zip` 里套 `.7z` 或假的 `.gb`(其实是个 HTML)。判断方法:看文件头——GB ROM 前 0x150 起有序列号区域;真 ROM 大小基本是 2 的幂(32K/512K/8M 等)。
- 刷完机没做 "Update game list / Scan games"。MinUI、EmulationStation 都需要手动重扫。

## 能进游戏但卡 / 声音爆音 / 掉帧
- **加速开关被开坏了**:RetroArch 的 `CPU Overclock`、`Frame Skip` 会让画面跳跃而不是流畅,先关。
- **着色器太吃性能**:CRT/HDR 类扫描线着色器在 Mali-G31 上能吃掉一半帧率,先关着色器确认基准。
- **音频缓冲太小**:爆音通常是 `Audio Latency`/`Audio Buffer` 设得过小(如 16ms)。调到 64ms 左右。
- **BIOS 缺失导致的"看起来像卡顿"**:某些 PS1 游戏在无 BIOS 时靠 HLE 兜底,过场动画会明显掉帧。
- 温度墙:安卓掌机长时间 PS1/N64 会降频,表现为"前 10 分钟正常之后越来越卡"。

## 存档丢了 / 读不了
- **两种存档别混**:`.srm`(模拟器即时存档/SRAM)与游戏内密码。刷机重装后 `.srm` 目录没备份就没了。
- 即时存档(save state)是**核心绑定**的:gambatte 的 state 不能给 TGB Dual 用;换核心后 state 会直接报版本不符。
- 改过 `Save directory` 设置后,老存档路径和新路径不一致 → 表现成"游戏从头开始"。找回方法:全盘搜 `.srm` 和 `.state` 文件名。

## 手柄/按键错乱
- 掌机自带按键映射在固件层(如 GarlicOS 的 remap 工具),RetroArch 层还有一套。两层都要对,否则会出现"菜单能用、进游戏方向反了"。
- 外接蓝牙手柄:先看固件是否原生支持该机型,再谈映射;多数 Linux 掌机对非标准 HID 手柄需要手动配置。

## 时间/日期每次重置
- 无 RTC 电池的机型(Miyoo Mini、RG35XX 老款)本来就会重置,靠 OnionOS 的"从 ROM 文件名/网络同步"或开机手动设。这不是故障。

## WiFi / 传文件
- 见 `../05-硬件与机型资料/win掌机文件传输共享.txt` 与 `Win掌机链接步骤.txt`(本库已收录)。
- 小文件推荐 LocalSend 类工具:掌机端有 `retsend`(LocalSend for retro handhelds,https://github.com/mxmgorin/retsend)。

## 想回原厂
- 原厂固件通常可以从厂商官网/客服拿到,但**刷机前务必把原厂 TF 卡和 NAND 镜像备份好**。RG35XX 系列一旦刷坏 bootloader 区域(极少见)就只能走 UART/JTAG,门槛很高。
- OnionOS/GarlicOS/spruceOS 类"纯 TF 卡固件"随时能拔卡回原厂,风险远低于要求写 NAND 的方案。选固件时这是重要判据。
