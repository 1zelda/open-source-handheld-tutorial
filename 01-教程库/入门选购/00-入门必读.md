# 入门必读:三件事决定你 80% 的体验

## 1. 先定"要跑到哪个平台",再定机器

开源掌机不是越强越好,而是**按目标平台选芯片档**。跑不到 N64 就不要为 N64 多花钱,因为跑 PSP 的钱是跑 N64 的好几倍。

| 你的目标 | 最低芯片档 | 价位段 | 典型机型 |
|---|---|---|---|
| 8–16bit(GB/GBA/FC/SFC/MD) | 全志 V3s / H700 / A133P | 200–500 | Miyoo Mini Plus、RG35XX H/Plus、Trimui Brick |
| + PS1 / N64(能玩,不追求画质) | H700 / T618 / G99 | 500–1200 | RG35XX 系、RG405M、RG Cube |
| + PSP / NDS 流畅 | 骁龙 865 / G3x / 天玑档 | 1400–3000 | Retroid Pocket 5、奥丁2、AYANEO Pocket S |
| + GC/Wii/PS2/3DS | x86 APU(Z1E、7840U) | 3000+ | Steam Deck、AYANEO 3、GPD Win 系列 |

机型详细参数看本库:`../../05-硬件与机型资料/安卓掌机对比表.txt`、`Win掌机对比表.txt`。

## 2. 存储卡是唯一真正的"高风险耗材"

90% 的"刷机失败/黑屏/丢档"根因都在卡上。要点:
- **品牌**:三星 EVO Plus / 闪迪 Ultra 及以上 / 金士顿。杂牌与"扩容卡"会随机丢文件,表现成"昨天还能玩的游戏今天打不开"。
- **容量**:≤128GB 最稳。256GB 以上在部分老固件(尤其全志 V3s 机型)读不了或识别慢。
- **格式**:CFW 通用要求 **FAT32 + 64KB 簇**。Windows 对大容量卡默认给 exFAT,要用 `SD Memory Card Formatter` 强制格式化成 FAT32。
- **速度**:A2/U3 足够;刷机速度取决于读卡器,别用前面板 USB 口。
- **备份**:原厂附带的卡**先整盘镜像保存**(Windows 用 `DiskImg`/`win32diskimager`,或 `dd`)。想回原厂时这是唯一救命稻草。

## 3. 固件选择决定你后面折腾的难度

| 固件类型 | 上手难度 | 优点 | 代价 |
|---|---|---|---|
| **原厂系统** | 极低 | 按键/驱动 100% 正常,可回退 | 游戏列表丑、core 版本老、无高级设置 |
| **OnionOS / GarlicOS / spruceOS**(TF 卡型) | 低 | 不写 NAND、随时拔卡回原厂;工具生态丰富(主题、联网、Pokedex 等) | 界面仍是 RetroArch/EmulationStation 逻辑,需要学目录约定 |
| **ArkOS / Knulli / Batocera**(通用镜像型) | 中 | 覆盖面广、核心新、可配置性高 | 需要按机型选对版本,按键驱动常要手动修 |
| **CrossMix-OS 等专用型** | 中 | 针对单机型调到最好 | 生态小、教程少 |
| **Windows/SteamOS 掌机** | 低(当 PC 用) | 什么都能装,性能最强 | 续航短、体积大、2D 老游戏需自己配前端(RetroDECK/Big Picture) |

**新手建议路径**:先用原厂系统 + 一张正规卡把游戏跑起来 → 再刷一个 TF 卡型 CFW(OnionOS/GarlicOS/spruceOS)对比体验 → 确认自己需要高级功能再上通用镜像型。

## 4. 第一天该做的 5 件事
1. 用读卡器把卡格式化成 FAT32/64KB,建好固件要求的目录(每个 CFW 文档站有目录树)。
2. 只放 5 个游戏测试:一个 GB、一个 GBA、一个 SFC、一个 MD、一个 PS1 —— 覆盖"无需 BIOS / 可选 BIOS / 建议 BIOS"三种情况。
3. 确认按键映射在菜单和游戏内都正确。
4. 设好存档目录,并搞清即时存档和 `.srm` 的区别(见 `../踩坑排查/00-常见故障速查.md`)。
5. 记下核心名字(不是游戏名),以后所有排错都要用到它。
