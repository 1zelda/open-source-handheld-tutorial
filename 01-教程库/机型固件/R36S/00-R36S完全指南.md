## 一、你的机器到底是什么

R36S 家族(R33S / R35S / R36S / R36H / R36S Plus / R36XX / G80CA 系克隆 / Y3506 "soysauce" 系)是同一块方案的套壳机:

| 项目 | 实测规格(上游 R36S-LINKS 规格表) |
|---|---|
| SoC | **Rockchip RK3326** |
| CPU | 4 × ARM **Cortex-A35**(4核4线程) |
| GPU | **Mali-G31 MP2** @520MHz |
| 内存 | **1GB DDR3L** |
| 屏 | 3.5" IPS,640×480,4:3(**至少 5 种面板版本**) |
| 存储 | **双 microSD 槽** |
| 喇叭 | 单声道 8W |
| 电池 | 3000/3200mAh(型号 804066,2pin JST 1.25mm 可拆换;商家标 3500mAh 是虚标) |
| 重量 | 约 187g |

一句话理解:**它是一台 RG351MP 的廉价克隆**(R36S ← R35S ← Powkiddy RGB20S ← Anbernic RG351MP)。所以你能用的固件和 RG351 系基本是同一批,这点很重要——它是 RK3326 生态,不是全志 H700 生态,**OnionOS / GarlicOS / muOS / knulli 都不支持它**。

## 二、刷机前必须做的第一件事:确认板型和面板

**这是 R36S 黑屏问题的唯一根源。** 面板版本不对 = 背光亮但屏幕全黑。

### 三条识别路径(按可靠性排序)
1. **拆机看主板丝印**:印着 `R36S-V12 2023-08-18`、`R36S-V21 2024-12-18 2551`、`R36S-V30 2025-11-18`、`R36S-Y02`、`G80CA-MB V1.2-20250423 Panel 8`、`Y3506_V04_20250529` 之类。这串编号就是 dArkOS 支持表里的 **Motherboard ID**。
2. **保留原厂卡 + 用 dtb 识别工具**:把原厂 TF 卡 `BOOT` 分区里的 `.dtb` 文件拖进 https://aeolusux.github.io/ArkOS-R3XS/tools/dtbIdentify.htm ,它会告诉你是哪块屏。**先备份原厂卡再动任何东西。**
3. **看 BOOT 分区 dtb 文件名**(应急判断):
   - `rk3326-r35s-linux.dtb` → 正常 R36S/R35S 系
   - `rk3326-evb-lp3-v12-linux.dtb` → ⚠️ **这是 EmuELEC 克隆版,ArkOS / AmberELEC 刷不进去**(2024-08 起出现,系统装在内建存储、关机也显示充电动画)。这类机器要走 EmuELEC/K36 路线,不要跟 R36S 教程硬刷。

本机已收录全部已验证板型与对应 dtb 路径的机器可读表:`../../05-硬件与机型资料/devices.json`
(本轮现数:`boards[]` **39 条**,含"已正式支持/Beta/无人验证"状态;它只覆盖 dArkOSRE/ArkOS-R3XS 认得的板子,
XiFan、GameConsole、Diium、UDT、AISLPC 等厂商机型**不在这张表里**,别拿它当"所有 RK3326 掌机"的支持名单)。

## 四、刷 dArkOS 的完整流程(照做,别跳步)

上游原文要点(完整版见 `上游wiki/dArkOSRE-R36/Firmware-Installation.md`,本地已存):

**准备**
1. **好卡**。上游在 `Firmware-Installation.md` 开头就挂了一篇《为什么一张好 SD 卡很重要》(https://www.reddit.com/r/R36S/comments/1r5zvqm/why_a_good_quality_sd_card_is_important/),本地另有一份实测记录 `上游wiki/R36S-LINKS/Firmware-and-SD-Card-Test.md`。R36S 对卡极敏感:建议三星/闪迪 64GB,不要用 256GB+ 和杂牌卡。
2. **不要插着电源做首次开机**(上游 CAUTION 明写)。
3. **先取出第二张卡**,装完再插回去。
4. **不要用 balenaEtcher** —— 大量用户报失败。推荐:**USB Image Tool**(作者首选)、Raspberry Pi Imager、Rufus、Win32DiskImager。

**写入**
5. 下载镜像压缩包后**不要用 WinRAR 解**(它会解坏),用 **7-Zip** 右键"Extract to"解出 `.img`。
6. **校验哈希**(强烈建议):PowerShell 里 `Get-FileHash -Algorithm SHA1 -Path .\dArkOSxxx.img`,和 Release 页给出的值比对。这一步能挡掉"下载截断导致的玄学黑屏"。
7. 用上面工具把 `.img` **Restore** 到 TF 卡。

**关键一步:换 dtb**
8. 卡写好后,Windows 下双击 BOOT 分区里的 **`SELECT MODEL`** 脚本 → 输入你的板型编号 → `Y` 确认 → 退出。
   macOS/Linux 则手动:删掉 BOOT 分区根目录所有 `.dtb`,再从表里对应目录复制正确的那一个到根目录(路径表见 `devices.json` 的 `dtb_path` 字段,以及 `上游wiki/dArkOSRE-R36/Firmware-Installation.md` 第 104-132 行)。

**首启**
9. 插回机器(仍然不要插第二张卡)→ 开机 → **首次启动 2–3 分钟**,期间不要断电。
10. 屏幕全黑?→ 大概率你是 **Panel 9**(克隆系)或面板选错:等安装完成后再按第 8 步换 dtb 重做,或重刷。
11. 最终进入 **EmulationStation** 即成功。

## 五、双卡布局(R36S 的正确姿势)

R36S 有 2 个卡槽,上游推荐:
- **卡 1(系统卡)**:dArkOS 镜像 + 主题 + Tools。它的 ROM 分区标签叫 `EASYROMS`。
- **卡 2(游戏卡)**:**exFAT 格式**,卷标自己起一个**独特名字(如 `ROMS2`/`ROMS`)——不要也叫 `EASYROMS`**,否则部分机器会主题丢失、启动异常。
- 卡 2 要先复制一份官方 ROMS 目录模板(上游 release 提供 template zip),然后在 ES 里:**START → Options → Advanced → Switch to SD2 for Roms**。
- Tools 目录默认仍挂在系统卡上(工具是机型相关,不跟 ROM 走)。要挪到卡 2 得改 `/etc/fstab` 里 `/roms2/tools` 的 bind 行。

## 六、ROM 放哪 / 扩展名 / 要不要 BIOS(常玩平台子集)

来源:`上游wiki/dArkOS/dArkOS-Emulators-and-Ports-information.md`(全 100+ 平台原文都在那个文件里)。目录在 ROM 分区的 `roms/<文件夹>` 下。

| 平台 | 目录名 | 扩展名 | BIOS |
|---|---|---|---|
| GB | `gb` | .gb .zip .7z | `gb_bios.bin`(**可选**) |
| GBC | `gbc` | .gbc .zip | `gbc_bios.bin`(可选) |
| GBA | `gba` | .gba .zip .7z .agb | `gba_bios.bin`(仅 lr-gpsp 等需要,mGBA/ VBA 可选) |
| NES/Famicom | `nes` | .nes .zip | 无;FDS 走 `fds` 目录 + `disksys.rom` |
| SNES | `snes` | .sfc .smc .zip | 无(MSU1 走 `snesmsu1`) |
| MD/SMS | `megadrive` / `mastersystem` | .md .gen .smd .bin | `bios_MD.bin`/`bios_E.sms`(可选) |
| PS1 | `psx` | .cue/.chd/.pbp/.bin | **`psxonpsp660.bin`、`scph1001.bin` 等,需要**(详细见 `03-BIOS库`) |
| N64 | `n64` | .z64 .n64 .v64 .zip .7z | 无;**64DD 需 `64DD_IPL.bin`** |
| NDS | `nds` | .nds | `nds_bios_arm7.bin` + `nds_bios_arm9.bin` 等(dArkOS 标"可选",但 HLE 有兼容损失) |
| PSP | `psp` | .iso .cso .pbp .chd | 无(PPSSPP 用替代固件可跑) |
| DC/Naomi | `dreamcast` / `naomi` | .chd .cue .cdi | **`dc_boot.bin` + `dc_flash.bin`**,且要放 `dc/` 子目录 |
| 土星 | `saturn` | .cue .chd .bin | `saturn_bios.bin`(标"可选",实际强烈建议) |
| PCE/CD | `pcengine` / `pcenginecd` | .pce .cue | CD 需 `syscard3.pce` |
| NEOGEO | `neogeo` | .zip | **`neogeo.zip` 必须**,与 ROM 同目录 |
| CPS1/2/3、MAME | `cps1`/`cps2`/`cps3`/`mame2003`/`mame` | .zip | 无(按核心版本选对应 ROM 集) |
| WonderSwan | `wonderswan`/`wonderswancolor` | .ws .wsc | 无 |

**R36S 上 dArkOS 的核心优先级(上游用粗体标"best")**:N64 = **mupen64plus standalone** > lr-parallel-n64 > lr-mupen64plus_next;PSP = **PPSSPP standalone** > lr-ppsspp。

## 七、性能现实:这台机器能做到什么、做不到什么

1GB DDR3L + Cortex-A35 + Mali-G31 MP2 的天花板是明确的:

| 平台 | 实际体验 | 建议 |
|---|---|---|
| GB/GBC/GBA/FC/SFC/MD/SMS/GBA 全系统 | **满速**,毫无压力 | 随便玩 |
| PS1 | 良好,PCSX-ReARMed/Beetle 基本全兼容 | 装 BIOS 后最稳 |
| NEOGEO / CPS / 街机 | 大部分好,PGM(三国战纪等)吃力 | 按兼容性表挑 |
| NDS | dArkOS 带 **Advanced Drastic**,3D 游戏(马里奥赛车DS等)会掉帧,2D 良好 | 挑游戏,别指望全部 |
| N64 | **这是本机的"及格线边缘"**:马里奥64/塞尔达时能玩时不能玩,大场景掉帧明显 | 先看 `R36S专用/R36S-Game-Compatibility-Lists`(已 clone 到本地,12MB,社区逐游戏实测表) |
| PSP | **多数游戏跑不动**;低 3D 需求的游戏在 1× 渲染分辨率下勉强 | 当作"能跑几款"而不是"能玩 PSP" |
| DC | Flycast 可跑 2D 与部分 3D,重 3D(VMU/高帧)吃力 | 同上,挑游戏 |
| GC/Wii/PS2/3DS/Switch | **不要期待** | 别为这些平台买 R36S |

想知道某个具体游戏能不能跑:先查本地 `02-模拟器库/已clone仓库/R36S专用/R36S-Game-Compatibility-Lists`(GazousGit,2026-08 仍在更新),这是逐游戏实测表,比任何笼统结论都有用。

## 九、这台机器的 128G 该怎么装满

商业 ROM 整合包我不下载,但 R36S 上"合法且量大"的内容其实很可观,足够装满卡片:

1. **PortMaster 移植游戏**:上游 `PortsMaster/PortMaster-New` 是 **34.6 GB**(整仓 clone 不现实,我没 clone 它),
   权威目录在 `PortsMaster/PortMaster-Info`(`ports.json` 1457 个移植游戏 + `devices.json` 40 个设备,已 clone 本地)。
   我据此筛出 **`attr.avail` 含 `r36s` 的 1393 个**,并从中分出 **551 个"下载即可玩、不需要自备游戏数据"**;
   本地已按 MD5 实下 **632 个包 / 21.32 GB**(`04-游戏资源库/公版与开源游戏/ports全量合法池/`),
   其中逐包审计确认 **548 个开箱能玩、84 个仍需自备素材**(素材免费可得的那些,来源链接已列在审计表里);
   另有 30 个小体积起手包(172.2 MB)。详见 `04-游戏资源库/公版与开源游戏/PortMaster移植游戏指南.md`。
   注意:一部分是"引擎移植"(doom、ScummVM、SteamWorld 等),**只提供引擎,游戏数据要你自己有**。
2. **homebrew / jam 合集**:GB Jam 各届合集(上百款)、GBA jam、NES jam。见 `04-游戏资源库/00-合法可下载资源索引.md`。
3. **开源游戏本体**:0 A.D.、SuperTuxKart 这类不适合 R36S,但大量轻量 2D 开源游戏可直接跑。
4. **你自己的卡带**:R36S 是 RK3326 + Linux,可以用 GB/GBA 烧录卡或让朋友帮你 dump;N64/PS1 光盘用电脑光驱直接镜像即可(你自己的盘)。
5. **用 `igir` 整理**(已 clone):把你手上零散文件重排成 `roms/<系统>/<游戏>` 结构,顺便去重与校验,一步到位喂给 dArkOS。

## 十、"XF45" 是什么机器?——已查明,而且它不是 R36S

上一版这里我写过"XF45 在所有上游资料里都找不到"。**那句话是错的**,原因很简单:我只在 R36S 的资料里找它,
而它根本不属于 R36S 家族的产品线。现已锁定:

**XF45 = XiFan HandHelds(稀范科技)XF45V**,同芯片(RK3326)但**屏幕是 1024×768**,不是 R36S 的 640×480。

三条硬证据(可复核):
1. arkos4clone 仓库 `boot/dArkOS/consoles/xf45v/` 里真的有 `boot.ini` + `rk3326-xf45v-linux.dtb`;
   `Changelog.md:218` 的 XiFan 支持列表含 `XF45V`;`dtbTools/internal/console/config.go:559` 写着
   `RealName:"xf45v", DisplayName:"XiFan XF45V", ExtraSources:{"logo/768P/"}`。
2. 我直接解析那块 dtb:`/dsi@ff450000/panel@0/display-timings/original` = `hactive 1024, vactive 768, clock 62000000`,
   4 lane MIPI-DSI。同档 `logo/768P/logo.bmp` 字节数 = 1024×768×24bit + BMP 头,互相印证。
3. 上游 `console-detect` 的 `resolution_map` 把 `"768p"` 定义为 1024×768,且 xf45v 的整条配置是
   `dual / happy5(FN 热键) / rotation 0 / ws2812 / otg manual / volume adc`。

**对你的直接影响**:本文第二节(确认板型/Panel Picker)、第三节(系统选择)、第四节(刷 dArkOS 的流程),
以及一切"选 640×480 主题 / 按 R36S 抄 dtb"的操作都**不适用于 XF45V**;ArkOS-R3XS、dArkOS、dArkOSRE、dArkOSen、P4ELEC、主线 ROCKNIX 都不带这个机型,
带它的是 **ArkOS4Clone**(dArkOS 系唯一)与 **AURKNIX**(ROCKNIX 分支,本轮实测 BOOT 里有 `rk3326-xifan-xf45v.dtb`)两条开源路。
