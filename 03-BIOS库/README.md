# BIOS 库

本目录是**归档与校验区**,不是下载区。三份文档:
- `00-BIOS需求总表.md` — 每个平台要不要 BIOS、要什么文件名、放哪、不装会怎样。
- `自制提取路径.md` — 从自有设备/官方免费渠道拿到 BIOS 的具体工具链。
- `校验方法.md` — "放了还是提示缺失"的 5 个原因。

子目录按平台划分(PS1/PS2/PSP/DC/NDS/GBA/_saturn/其他),把你提取到的文件按模拟器要求的命名放进去,然后:

```
python ../_工具脚本/bios_check.py
```

生成 `_bios_inventory.json` 与各文件 MD5,再到模拟器的 BIOS 面板核对期望值。
