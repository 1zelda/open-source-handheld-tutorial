# 自制 BIOS 提取路径(按平台)

> 原则:**从你手里那台机器/那张光盘/官方服务器导出的东西,是你唯一可以长期依赖的来源。**
> 本文件只列官方渠道和公开工具链,不列任何"BIOS 合集包"。

## 有官方免费下载的(最省事)

| 平台 | 官方来源 | 说明 |
|---|---|---|
| PS3 | PlayStation 官网 `PS3 System Software Update` → `PS3UPDAT.PUP` | RPCS3 直接 File → Install Firmware 指向这个文件即可,**完全合法且免费** |
| PSP | Sony 官方 5.00 升级安装包(`PSP_FW500_*.EGA3.PSP`) | 官方 updater 里含 `flash0` 组件;PPSSPP 也可以走"模拟固件(ProFX)"先跑起来 |
| Wii / WiiU | Nintendo 官方系统更新(WiiU 固件包可从 nintendo 支持站取) | Dolphin 主要需要的是密钥导入提示,不强制手动放文件 |

## 需要自有设备 + homebrew 提取的

| 平台 | 工具 | 大致步骤 | 产出物 |
|---|---|---|---|
| NDS | `bloodworth/dsdump`(旧机)或 DSi 上的 homebrew | 在 DS 上跑 dump 卡 → 读 SD | `firmware.bin`(76KB 正式版;`7Fh` 是工程版,模拟器可能拒收) |
| 3DS | Homebrew Launcher + `firmware installer` / GodMode9 | 用 GodMode9 导 `sysNAND`,或直接跑官方固件安装脚本 | `sysdata/` 所需系统标题 |
| Switch | `hacmount`/`lockpick` 类密钥导出工具(需自有机 + 已破解系统) | 在机子上运行导出 → 拷出 keys | `prod.keys`、`title.keys`、`package3` 固件 |
| PS1 | 原生 PS 用 memory card 导出法(经典方法),或 PSX/PSOne 上跑 homebrew | 用带导出功能的 MC 工具盘把 BIOS 区域读出来 | `scphXXXX.bin`(看你的机型) |
| PS2 | FreeMcBoot 记忆卡 + `PS2 BIOS dumper` 类 homebrew | 在已装 FMCB 的 PS2 上运行 dumper,输出到 U 盘/MC | `SCPHxxxx.bin`(注意区分机型与版本,模拟器会做校验) |
| Dreamcast | SD 读卡器 homebrew(Ika/DC-Boot 路线) | 从自有 DC 导出 boot ROM | `dc_boot.bin` + 字体文件 |
| 世嘉土星 | 自制引导卡 + 导出工具(门槛较高) | 需要额外硬件 | `saturn_bios.bin`(美/日/欧) |

**提示**:PS1/PS2 的提取是目前门槛最高的一档,因为需要老主机 + 自制引导。如果你的目标只是"能玩",优先顺序建议:
1. 先用不需要 BIOS 的核心把游戏库跑起来(FC/SFC/MD/GBA/GBC/PSP 大部分游戏可无 BIOS 或走替代固件);
2. 再针对性解决 PS1(用 PCSX-ReARMed 的 HLE,或 DuckStation + 官方免费途径);
3. 最后才折腾土星/DC。

## 平台目录结构建议

模拟器最在意路径。推荐这样摆放(与 `00-BIOS需求总表.md` 对应):

```
03-BIOS库/
├── PS1/
│   ├── PSX.EXE
│   └── scph5500.bin  scph5501.bin  scph5502.bin
├── PS2/
│   └── SCPH10000.R3303.bin …
├── PSP/
│   └── flash0/  (目录!内含 font0.dat、lh5-4.stg、imageman*.bin 等)
├── NDS/
│   └── nds_biios.bin   (注意:文件名里 i 的个数按所用模拟器文档为准)
├── DC/
│   └── dc_boot.bin  dc_font.bmp
├── _saturn/
│   └── saturn_bios.bin  (美/日/欧分别命名)
└── 其他/
    └── 各冷门平台按核心提示命名
```

掌机里实际路径通常要再映射一次:`BIOS` 目录在 RetroArch 设置里指定(如 `/mnt/roms/BIOS` 或 `~/BIOS`)。文件在本库是为了**归档与校验**,真正运行时要复制或软链到模拟器读取目录。

## 校验

放好文件后运行:
```
py -3 _工具脚本/bios_check.py
```
它会输出每个文件的 MD5。然后打开模拟器的 BIOS 面板,把它列出的**期望 MD5** 与你这份对一遍。这是唯一可靠的确认方式——因为网上抄来的 MD5 表经常是错的。

## 本地已备好的提取与校验工具(已 clone)

| 工具 | 用途 | 本地路径 |
|---|---|---|
| **mgba-emu/bios-dump** | 用 **自有 GBA/GBASP 主机 + 烧录卡** 导出 `gba_bios.bin`。流程:编译 `.gba` payload → 在掌机运行 → 通过链接口把 BIOS 传给电脑 | `02-模拟器库/已clone仓库/工具与ROM管理/bios-dump` |
| **ShendoXT/biosdumper** | 从 **自有 PS1/PS2 主机** dump BIOS(配合 homebrew 记忆卡/引导) | `02-模拟器库/已clone仓库/工具与ROM管理/biosdumper` |
| **libretro/libretro-database** | 官方 RDB / DAT 合集:**ROM 与 BIOS 的标准哈希与命名**就在这里,是"我这个文件到底对不对"的权威答案来源,比博客抄的 MD5 表可靠 | `02-模拟器库/已clone仓库/工具与ROM管理/libretro-database` |

用法提示:`libretro-database` 里的 `rdb/` 与 `hash/`(XML DAT)可以用 `igir` 直接拿来做校验与重命名 —— 见 `04-游戏资源库/00-合法可下载资源索引.md` 第六节。

## dArkOS / ArkOS 的 BIOS 目录约定(R36S 等 RK3326 机器)

- BIOS 放在 ROM 分区的 **`bios/`**(不是 `BIOS/`),部分核心还要求子目录:
  - Dreamcast:`bios/dc/dc_boot.bin` + `dc_flash.bin`
  - Atomiswave / Naomi:固件要打包成 `bios/awbios.zip` / `bios/naomi.zip`
  - Neo Geo:`roms/neogeo/neogeo.zip`(和 ROM 同目录,不是 bios 目录)
  - PS1:`bios/scphXXXX.bin` 或 `bios/psxonpsp660.bin`(Beetle/ReARMed 都吃)
  - PSP 的 `flash0`:PPSSPP standalone 走自己的配置目录,不在 `bios/` 下
- 权威逐平台清单在本地 `01-教程库/机型固件/R36S/上游wiki/dArkOS/dArkOS-Emulators-and-Ports-information.md`(100+ 平台,每行都写了 Rom Folder / Extensions / Bios)。
