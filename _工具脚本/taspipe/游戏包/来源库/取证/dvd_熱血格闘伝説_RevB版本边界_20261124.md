## 与原版 FC 的边界

- Rev.B 是 NES 四人手柄本地化补丁，不是原版日版 FC 卡带能力。
- README 明写：只能在 NES 4-Score 或 NES Satellite 模拟下支持第3、第4玩家；不支持 Famicom 第3、第4玩家模拟。
- 四人能力只在 Rumble（对战）模式；不得回写成原版 FC 的通用能力。
- 补丁目标文件含16字节 iNES 头时为262,160字节； mapper 4（MMC3）。
- Rev.B 修正了错误起始 ROM 的3处压缩画面数据差异；因此 Rev.B 产物不能冒充未修改原版权威证据。
