 Useless topic is useless.

If your file is in the fm3 format (TAS Editor)
File > Export to FM2
(You know the thing you should do before submitting, instead of submitting an evil fm3 file, which is possible.)

Now within BizHawk.

Run NES Game.
Drag & Drop the FM2 into Hawk.
Congrats, your movie is converted.

---

If those simple 3 steps didn't work here's the other way:

Run NES Game.
File > Movie > Import Movies...
Find the FM2 file you wished to convert.
