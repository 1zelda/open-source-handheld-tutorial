## 1. 发动与状态规则（S1 原文，生产闸门依据）

- 必杀踢射：持球跳（A+B）到**最高点按 B**；**发动时不能按方向键**，否则变成挑球不是人球同跳。
- 难度：`やさしい` 容易 = 敌我**都不能**发动必杀射门；`ふつう` 普通 = 次次发动；`むずかしい` 困难 = 仅会燕返者 100%。
  ⇒ 采集必须在普通难度（导航默认值待实测确认；若必杀不触发先查难度）。
- 秘技：比赛中 Start 暂停 → A×3 B×1 A×3 B×1 A×7 → Start 解除，听到必杀音效=成功；全员获得全部**技能**（燕返/爆裂等）。
  **效果只持续半场**；射门种类仍按角色身份（秘技不改射门种类）。
- 1P 固定控制**中场队长**；等候室「作战会议→位置」可把任意队员换到 MF ⇒ 逐角色采集的换人路线。
- 队友持球时**按住单发 B 不放**才能指挥队友发动必杀踢射（否则只跳不踢）⇒ 备选采集路线。
- Hyper Shoot（超常踢射/电光球）：把握好时机倒挂金钩/跳跃头球使球带电；跑动中 A+B 跳后按 ↓B = 电光球射门。
- 倒挂金钩：球附近跳起后 **方向后+B**；鱼跃头球：球附近 **←B 或 →B**（S1 操作表）。
