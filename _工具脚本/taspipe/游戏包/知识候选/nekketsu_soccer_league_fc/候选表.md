> 共享前置：球权在目标角色脚下 + 普通档 + 已解锁活球段；目标角色可控（换位/指挥，见 `逐角色资格矩阵.md` §4-1）。

### D1. hyper_shoot — 超级射门（通用射门增强态）

| 字段 | 内容 |
|---|---|
| ID | `hyper_shoot` |
| 名称 | ハイパー・シュート Hyper Shoot（超级射门/超常踢射/电光球） |
| 所属角色·资格 | **通用**，非逐角色；由倒钩/跳头球在足够高打点时机炸裂（M L258；F L351） |
| 版本 | 同 A1 |
| 前置场景 | 自由球附近、足够高打点；普通档 |
| 触发方法 | 倒钩（跳起后方向后+B）或鱼跃头球（←B/→B）在**高打点时机**炸裂使球带电（M L258/F L351）；跑动 A+B 跳后 ↓B=电光球（L §1）；宏 `未实证` |
| 可观测前置 | 自由球、高打点、目标角色可控 |
| 成功特征 | **球带电**（F L351）；比必杀射门更强；检测 `未实证` |
| 易混淆普通动作 | 普通必杀射门（不带电）；天气闪电（带电假阳） |
| 困难反例 | 低打点倒钩/头球（应不出带电）；同 base 不按 B；天气闪电假阳 |
| 原文·页码·链接 | M L258；F L351；L §1/§3 电光球 |
| 证据等级 | 机制=官方全文(M)+全文(F)；宏/检测=未实证 |
| 尚需探针 | 高打点时机帧窗；带电真色/判据；与天气闪电区分 |

### D2. 个人技（通用操作，官方操作说明，人人可用，不计必杀覆盖）

> 来源 M＜操作説明＞L185–251 + 编者对照 L41–50。这些是**基础操作**，不是必杀技，单列以免与必杀覆盖混淆。

| ID | 名称 | 触发（官方） | 备注 |
|---|---|---|---|
| `jump` | 跳跃 | A、B 同时按 | 必杀射门的前置动作 |
| `hyper_dash` | 超级冲刺 ハイパー・ダッシュ | 冲刺中十字键按行进方向连按 2 次 | 龙卷踢/钻子前置（裏技口径） |
| `heel_lift` | 脚跟颠球 ヒール・リフティング | 持球时十字左或右 + A、B 同时按 | 11-14 实测可复现（L §1）；困难档挑球前置 |
| `feint_attack` | 假动作攻击 フェイント・アタック | 冲刺运球中十字上或下连按 2 次 | 与必杀运球同输入类别，须区分 |
| `diving_head` | 鱼跃头球 ダイビング・ヘッド | 自由球附近十字左或右 + B | 高打点时机=Hyper Shoot |
| `overhead` | 倒钩 オーバー・ヘッド | 自由球附近跳跃 + 十字后 + B | 高打点时机=Hyper Shoot |

**诚实边界**：个人技宏帧号/检测全部 `未实证`；脚跟颠球 11-14 有探针级证据（L §1）但非 calibrated bundle。合体移动/合体技（芋虫式/踩球/合体）官方"依状况还有"（M L251），**逐条发动法文献确无**（L §8-2 更正：S10 只提及存在，无逐条发动法），待实测。
