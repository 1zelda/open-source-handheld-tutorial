以下是整个排查过程的坑点总结和必须完成的设置清单，以后换设备或重装系统时直接照着做。
一、踩过的坑
表格
坑	现象	根因
1. 微软账户无法用于 SMB 共享	提示"此用户无法登录，因为该账户当前已被禁用"	Win11 家庭版默认微软账户登录，但 SMB 协议只认本地安全账户数据库，微软账户凭据不走这条通道
2. 本地账户没设密码（或密码不对）	net use 显示成功但 dir \\IP\d 报"拒绝访问"；或带密码连接时报"错误 1326 用户名或密码不正确"	Windows 默认禁止空密码账户从网络登录共享资源。即使 net use 不带密码显示成功，也只是匿名回退，访问真正受限资源时会被拒绝
3. 只设了共享权限，没设安全权限（NTFS）	能看到文件夹，但打不开/无法写入文件	共享权限只控制"网络准入"，安全权限控制"实际读写"。两道门都要开
4. 访问端凭据缓存混乱	改完权限后还是进不去，或有的文件夹能进有的不能	Windows 会对不同共享路径（\\IP\d、\\IP\Users）缓存不同凭据，旧缓存会覆盖新配置
5. 在 cmd 里直接输入 \\IP	报错"文件名、目录名或卷标语法不正确"	\\IP 是资源管理器路径语法，不是命令行语法。cmd 里要用 net use 或 explorer \\IP
6. 共享 D 盘根目录，但子文件夹进不去	D 盘下的"新建文件夹"无法访问	访问 \\IP\d\子文件夹 时，系统先检查 D 盘根目录是否允许"经过"，根目录权限不足会拦截子文件夹
7. 以为"没有密码"	反复连接失败	创建本地账户时 Win11 可能强制要求设密码，或之前已设过但忘记了。必须确认实际密码是什么
二、必须完成的设置（成功公式）
掌机端（OneXPlayer / Win11 家庭版）
1. 确认/创建本地账户
如果只有微软账户，必须新建本地账户：
设置 → 账户 → 其他用户 → 添加账户 → 我没有这个人的登录信息 → 添加一个没有 Microsoft 账户的用户
记录好用户名（如 one）和密码
2. 启用本地账户
cmd
net user one /active:yes
3. 确认或重置密码（关键）
cmd
net user one 你的密码
必须确认密码有效，不能留空。
4. 打开系统级共享开关
控制面板 → 网络和共享中心 → 更改高级共享设置
专用网络：启用网络发现、启用文件和打印机共享
所有网络：关闭密码保护共享（可选，如果已用账户密码连接可不管）
5. 共享文件夹 + 双权限（最关键）
右键目标文件夹 → 属性：
共享 → 高级共享 → 权限：添加 one → 完全控制
安全 → 编辑 → 添加：输入 one → 检查名称 → 完全控制
两个选项卡都要加，缺一不可。 如果只共享 D 盘根目录，子文件夹也要单独确认安全权限。
访问端电脑
6. 清除旧凭据缓存
cmd
net use * /delete /y
7. 用本地账户建立连接
cmd
net use \\192.168.2.13\共享名 /user:one 密码
必须带密码参数。显示"命令成功完成"才算真通了。
8. 验证底层连通
cmd
dir \\192.168.2.13\共享名
能列出文件，说明权限和认证都对了。
9. 资源管理器访问
按 Win + R 输入 \\192.168.2.13\共享名 回车
或映射网络驱动器：net use z: \\192.168.2.13\共享名 /user:one 密码
三、一句话总结
同一局域网 + 本地账户（必须有密码）+ 共享权限和安全权限双加完全控制 + 访问端 net use 带密码预连接 = 成功。
