  • 来源审计唯一失败项不是语料损坏，而是 gba_aria_of_sorrow_souls.showcase.json 使用了 schema 未登记的 evidence_report 字段；同一来源当时还未进入 sources.json，包内 verified 也与原始报告的 verified_in_game=false 冲突。
  • 修正分三层：把合法字段纳入 schema；校验包内来源 ID、状态与注册表一致，并校验 evidence_report 指向存在且非空的文件；按真实证据范围重新分级，不用任务完成状态代替机制验证。
  • aria_showcase2 可登记为限定范围的 verified_read；aria_soul_gameplay4 保持 candidate。后续 RAM 校准只证明它实际覆盖的字段，不追溯洗白旧候选报告。
