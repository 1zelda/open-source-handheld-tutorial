## 1. 落地改法（双索引，bm25 兜底构造零回归）

### 1.1 为什么双索引而不是单索引再索引

对照件在 corpus_map entries #1/#3（插中间非末尾）。单索引再索引会移动 base 块 ci ⇒ bm25 兜底臂的 postings/anchor 全变 ⇒ 无法保证零回归。
**双索引规避**：base `index.json`(625) + npz 一个字节不动；新建 `index_hybrid.json`(639=625+14 对照) + npz 只给 hybrid 臂。bm25 兜底走 base，构造上与 P7 完全相同。

### 1.2 代码改动（4 文件）

| 文件 | 改动 |
|---|---|
| `taspipe/kb.py` | ENTRY_KEYS 加 `hybrid_only`；load_map 校验（须 bool、只能挂 index:false 件）；`hybrid_index_path()` 助手（跟随 INDEX_JSON，探针隔离安全）；build 加 `hybrid=False` 参数 + skip 块（hybrid_only 件 base 排除、hybrid 收录）；`_select_index()`（显式尊重文件名、默认 ready 探测自动选臂）；`_bm25_scores(domain_local)`（False=全局原公式逐字、True=域内 N/df/avgdl）；query 选臂 + 打分接线 + scoring_note；CLI `build --hybrid`（默认落 index_hybrid.json） |
| `taspipe/kb_dense.py` | `import json`；`ready(index_path)` + `_ready_cache`（指纹件存在/sha 一致/块数相符/sentence_transformers 可导入，按 mtime 缓存；检查在重模型导入前） |
| `游戏包/知识库/corpus_map.json` | 2 对照件（setsumei/urawaza 编者中文对照）加 `hybrid_only:true`（保留 index:false + reason 历史），note 追加 P10 启用说明。**译文 md 字节不动** |
| `taspipe/kb_selftest_gates.py` | +12 格 [108]-[119]（hybrid_only schema 正/反证、base 排除/hybrid 收录、base⊂enriched、域内 IDF 隔离、domain_local=False 逐块等于全局原公式、自动选臂兜底/显式/正对照） |

### 1.3 域内 IDF 公式（与 P9 模拟逐字一致）

```
domain_local=True:  N=len(cand)  avgdl=候选池均值  df=池内计数(df==0 跳过)
domain_local=False: N=idx.stats.N  avgdl=idx.stats.avgdl  df=len(post)   # base 主干逐字原样
idf=log(1+(N-df+0.5)/(df+0.5));  score+=idf*tf*(K1+1)/(tf+K1*(1-B+B*dl/avgdl))
```
闸门 [115] 恒量反证：domain_local=False 逐块等于手工全局 BM25 原公式（误差<1e-9）⇒ 兜底臂构造零改动坐实。

### 1.4 自动选臂（默认检索随环境）

`query(index_path=None)` → `_select_index(None)`：`kb_dense.ready(hybrid_index_path())` 就绪→富集+域内；否则 base+全局。
评测脚本 `prod_eval.py`/`p23_probe.py` 用默认 index_path ⇒ **零改动**，臂随环境（venv→hybrid，系统 py→bm25）。显式 index_path 尊重调用方（文件名 index_hybrid.json→域内）。
