## 3. T1 实测：权威表 vs 派生副本（全部臂等长 = 4 空帧，同一个 root `cut_spawn.state`）

| 臂 | 补丁 | 读回 `$0022` / `$0025` | 相机 `$001A/$001B` | 与基线像素差 |
|---|---|---|---|---|
| `ctl_none` | 无 | 128 / 148 | 0 / 0 | 0（恒量基线） |
| `derived_ctl` | `$0022=200` | **128** / 148 | 0 / 0 | **0** |
| `x_only` | `$0480=176` | **168** / 148 | **40** / 0 | **20,042（34.95%）** |
| `scr12` | `$0460=12` | 232 / 148 | 0 / **3** | 566 |
| `bossroom` | `$0460=12,$0480=32,$0600=84` | 232 / **84** | 0 / 3 | 566 |

看图定案（`F:/taspipe_scratch/mm_nav/t1/t1_sheet.png`、`t1_zoom_right.png`）：
- `derived_ctl` 与基线**逐像素相同** ⇒ 写显示副本 = 完全无效，不是"没测出来"。
- `x_only` 相机整屏右滚 40 px ⇒ 写 `$0480`（X hi）**真的把角色搬动了**，游戏从这张表重算显示量。
- `bossroom` 角色被抬到半空（y=84，画面右上角悬着） ⇒ 写 `$0600`（Y hi）**逐字生效**。
- `scr12`：写 `$0460=12` 被引擎重算成 **3**，X 同步变 232 ⇒ 屏号是派生量，不能指定房间。
