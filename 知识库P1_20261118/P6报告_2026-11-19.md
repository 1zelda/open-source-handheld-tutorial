## 6. 环境插曲（已解决，如实记录）

hybrid 臂首跑报 `OSError: BAAI/bge-reranker-v2-m3 does not appear to have a file named model.safetensors`。根因：Git Bash 里 `set HF_HUB_CACHE=F:/kb_pilot_hf_cache&&` **不导出环境变量**（bash `set` 是设 shell 选项的 builtin，不是 cmd 的 set）；系统持久 `HF_HOME=D:\HuggingFaceCache\huggingface` 生效 ⇒ venv 扫 D 盘旧缓存 ⇒ 模型文件不存在。改用 `export HF_HUB_CACHE="F:/kb_pilot_hf_cache"` 正确导出后，venv 内 constants.HF_HUB_CACHE 指向 F 盘、model.safetensors（2271071852B）存在，hybrid 评测/探针跑通。

教训：Git Bash 设环境变量一律 `export`，别用 `set VAR=val&&`；本机系统持久 HF_HOME 会覆盖未正确导出的 HF_HUB_CACHE。模型加载慢（三盘近满、F 盘 open 延迟高）但能完成——进程 alive + GPU 内存增长 = 正常推进，别误判死锁就杀（与 P5 §7 同源教训）。
